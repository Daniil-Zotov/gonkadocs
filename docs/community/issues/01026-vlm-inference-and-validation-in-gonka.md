# Title
VLM inference and validation in Gonka
## Summary
Test the possibility of VLM serving validation, add the necessary tools
## Motivation
Gonka already employs validation of token sequences generated by distributed nodes serving large language models (LLMs), which enables the detection of fraudulent behavior and dishonest model hosting. A logical next step is to add visual language models in the set of serving models.
## Impact
- [inference](https://github.com/machine-intelligence-laboratory/gonka/blob/b5628a92bcbad3a7c5f5f2786f32e30fd3364541/mlnode/packages/benchmarks/scripts/inference_validation/vlm_inference.py) and [validation](https://github.com/machine-intelligence-laboratory/gonka/blob/b5628a92bcbad3a7c5f5f2786f32e30fd3364541/mlnode/packages/benchmarks/scripts/inference_validation/vlm_validation.py) scripts for visual language models
- tests


## Expected outcome 
- possibility of the VLM serving in Gonka
- tools for validation

## Proposed approach
- add necessary tools in MLNode
- Do image-related tasks on the one machine, save artifacts and validate them on the other machine. Include threshold calibration, using "honest" and "fraud" scenarios with "small" (~2B) and "large" (235B) models
- PR in gonka repo

## Intermediate results

Results for "small" visual models 
- [Qwen2-VL-2B-Int4](https://huggingface.co/Qwen/Qwen2-VL-2B-Instruct-GPTQ-Int4)
- [Qwen2-VL-2B-Int8](https://huggingface.co/Qwen/Qwen2-VL-2B-Instruct-GPTQ-Int8)
validation are available [here](https://github.com/machine-intelligence-laboratory/gonka/blob/b5628a92bcbad3a7c5f5f2786f32e30fd3364541/mlnode/packages/benchmarks/notebooks/qwen2-2B-VL_thresholds.ipynb)
For these models F1-score for fraud-detection task is 100%.

Results for large "models" will be added a bit later.
