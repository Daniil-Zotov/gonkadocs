About this portal

Gonka Docs is a meta-repository for the Gonka decentralized AI inference network (Proof of Compute consensus). It aggregates everything about the project in one place: auto-synced protocol documentation, a full source code mirror, community discussions and issues, governance proposals with funding tracking, and live community funds — continuously synced from their sources and designed agent-first for AI assistants.

Documentation & code

  • Protocol documentation — architecture, quickstarts, wallet, governance (EN / 中文)
  • Source code mirror of gonka-ai/gonka, indexed by gonka-code-map.txt

Community

  • GitHub Discussions — proposals, Q&A, show-and-tell
  • GitHub Issues — bugs, features, enhancements
  • Roadmap, calendar, activity feed and committees (GRC / GSC / GPC / GTM)

Governance

  • On-chain proposals — quarterly overviews, funding sources, reports, tally results
  • Pre-proposals — off-chain community polls from gonka.vote
  • Community funds — balances and spend history

For AI agents

Single source of truth for AI assistants: machine-readable llms.txt and llms-full.txt, .html.md page copies, an OpenAPI spec, sitemaps, RSS, and an MCP server.
