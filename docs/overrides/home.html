About this portal

Gonka Docs is a meta-repository that aggregates everything about the Gonka decentralized AI inference network in one place: the official protocol documentation, a mirror of the source code, community discussions and issues, governance proposals, and the development roadmap — all continuously synced from their sources.

Documentation & code

  • Protocol documentation — architecture, quickstarts, wallet, governance
  • 中文 documentation — Chinese translations
  • Source code mirror of gonka-ai/gonka, indexed by gonka-code-map.txt

Community

  • GitHub Discussions — proposals, Q&A, show-and-tell
  • GitHub Issues — bugs, features, enhancements
  • Roadmap — three-horizon strategy
  • Calendar and activity feed

Governance

  • On-chain proposals — quarterly overviews with funding, reports, tally results
  • Pre-proposals — off-chain community polls
  • Community Pool — balances and funding history
  • How to Propose — three ways to submit a proposal

For AI agents

Designed as a single source of truth for AI agents: machine-readable llms.txt, llms-full.txt, an OpenAPI spec, and a setup guide covering agent rules and an MCP server.
