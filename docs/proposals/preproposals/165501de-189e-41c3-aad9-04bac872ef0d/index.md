## Full Proposal

QRMint × Gonka
AI Game Hackathon Proposal
Summary

QRMint proposes an AI Game Hackathon in partnership with Gonka focused on attracting new developers to the Gonka ecosystem and encouraging them to build playable, long-term games powered by AI and Gonka infrastructure.

The goal is not to create another short-lived hackathon demo.

The goal is to create games that people actually want to play — and that can continue evolving after the hackathon.

The proposed hackathon would offer a $30,000 prize pool for the Top 3 games, creating a strong incentive for teams to build ambitious and sustainable projects.

Why Games?

Games are one of the strongest ways to turn technical infrastructure into something users can actually experience.

Instead of developers simply integrating Gonka into another technical demo, the hackathon would encourage them to build:

AI + Blockchain + Games

This creates an accessible entry point for developers who may not otherwise experiment with Gonka.

A successful game can continue attracting:

players;
developers;
creators;
communities;
AI experiments;
new applications.

The game becomes a distribution layer for the ecosystem.

Hackathon Goal
Attract new developers to Gonka.

We want to create an environment where developers can experiment with:

AI-powered gameplay;
autonomous AI agents;
AI-generated content;
AI-controlled opponents;
dynamic game worlds;
blockchain-based game mechanics;
on-chain game events;
new ways of using Gonka infrastructure.

The strongest projects should have the potential to continue developing after the hackathon.

What We Are Looking For
1. Long-Term Potential

Projects should have the potential to become real games rather than one-time hackathon prototypes.

Games should have mechanics that allow for:

continued development;
new content;
recurring player activity;
competitions;
communities;
future monetization.
2. Multiplayer & Competition

Multiplayer is encouraged.

Possible formats include:

1v1 matches;
multiplayer games;
competitions;
tournaments;
rankings;
leaderboards;
challenges.

However, multiplayer is not mandatory if the game has a strong alternative gameplay loop.

3. Different Game Formats

Developers are free to experiment with different formats.

For example:

Level-based games

Games can contain levels, progression and their own story.

Score-based games

Players compete for the highest score and positions on leaderboards.

AI-powered games

AI can control opponents, generate content, create events or dynamically change the game.

Autonomous agents

AI agents can participate in gameplay and interact with other players or game systems.

The goal is to give developers freedom rather than force everyone to build the same type of game.

Gonka + AI

A key part of the hackathon is exploring meaningful use of Gonka infrastructure in AI-powered games.

We want developers to experiment with ideas such as:

AI opponents;
AI NPCs;
autonomous game agents;
AI-generated levels;
AI-generated game content;
dynamic game scenarios;
AI-driven game events;
AI agents interacting with game data;
other applications that emerge during the hackathon.

The integration should provide meaningful value rather than being added only to satisfy a technical requirement.

Open Game Data

Another important part of the concept is open game data.

Games can expose structured data through APIs so that other developers can build services around them.

For example:

player statistics;
match results;
scores;
rankings;
tournament results;
achievements;
game events;
AI agent activity;
digital assets;
other structured game data.

This allows one game to become the foundation for multiple applications.

Game → Open Data → Developers → New Services → New Users

Potential applications could include:

analytics;
AI tools;
prediction and forecasting applications;
tournament platforms;
community applications;
bots;
creator tools;
Web3 applications.

This creates an ecosystem around the game rather than keeping all value inside the original application.

Evaluation Criteria

Projects could be evaluated based on:

🎮 Gameplay

How fun, engaging and playable is the game?

🤖 AI Innovation

How meaningfully does the project use AI?

⛓️ Gonka Integration

How meaningfully does the project use Gonka infrastructure?

📈 Long-Term Potential

Could the project continue growing after the hackathon?

👥 Community & Multiplayer Potential

Can the game create recurring player interaction?

🔓 Open Data

Can other developers build applications or services around the game's data?

💡 Originality

Does the project introduce an interesting new idea?

Distribution

QRMint can also contribute to the distribution and visibility of the hackathon and resulting games.

Potential channels include:

Telegram;
TikTok;
YouTube;
developer communities;
Web3 communities;
gaming communities;
creator-generated content.

A particularly important goal is to turn winning games into ongoing content, rather than stopping promotion when the hackathon ends.

Long-Term Vision

The hackathon is designed as the beginning of an ecosystem rather than the final event.

The desired cycle is:

Gonka Infrastructure
↓

Developers
↓

AI Games
↓

Players
↓

Open Game Data

↓

New Developers & Services
↓

More Players
↓

More Ecosystem Activity

Core Principle

Don't just build another AI demo. Build a game people actually want to play.

The QRMint × Gonka Game Hackathon would give developers a reason to experiment with Gonka today while creating projects that can continue contributing value to the ecosystem long after the hackathon ends.
