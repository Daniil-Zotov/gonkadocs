# On-Chain Governance

The Gonka network uses on-chain governance for protocol upgrades, parameter changes, model registrations, and community pool spending.

**Current active proposals:** see the [On-Chain Governance dashboard](/proposals/proposals/).

| Voting Period (standard) | 48 hours |
| Voting Period (expedited) | 12 hours |
| Quorum | 25% |
